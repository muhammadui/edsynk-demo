Roles & permissions

what each HQ role can do

Super-admin

Everything — billing & refunds, suspend/restore tenants, impersonate (with consent), manage content, rotate keys, flip feature flags. 2FA enforced, no exceptions.

Support lead / agent

Read-only tenant info, support inbox, resend invoices. No billing changes, no suspension. Impersonation only with a ticket reference + school consent.

Onboarding

Provision new schools, run data imports, deliver training. No billing, no danger-zone actions on live tenants.

Finance

Invoices, payments, reconciliation, plan changes. Read-only everywhere else. Cannot impersonate.

Impersonation always needs consent + a reason.

Logging in as a school's user requires an open ticket reference and the school's consent, auto-ends after 30 minutes, and is written to the audit log. This is the same flow exposed on each school's record.
